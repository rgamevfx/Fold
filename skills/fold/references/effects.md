# Reusable image effects and timing

> **Pre-rewrite reference — 8 October 2026.** These examples describe the old build. For new motion/MCP/agent work, use the [Motion System Rewrite Plan](../../../docs/Motion_System_Rewrite_Plan.md); this guide supplies no compatibility requirement. Requalify examples against the replacement public contract before publishing them as supported.

Phase 57 introduces published Compositing/Composition definitions and instance-owned values. Discover the current package catalog before authoring; older running builds do not support this contract.

The [reusable dissolve batch](../examples/reusable-dissolve.json) is exercised by `fold-app/tests/reusable_effects.rs` through the same public batch staging API. It creates an editable Dissolve definition, two partly transparent sources and an Instance node. The test verifies one-step undo/redo, save/reopen and true premultiplied interpolation. This is an API regression example, not a completed live desktop/MCP workflow qualification.

Fetch `catalog guide="effects"` to receive the guide and its `example` batch without filesystem access. To use the example, replace `revision`, `project_epoch` and `request_id` with current observed state and a fresh request identity. Submit through `batch` or a private candidate, poll the job, and use returned `ids.host` for rendering. At time 1/2 second the expected working pixel is `[0.25, 0, 0.125, 0.375]`. Do not assume an sRGB screenshot has those numeric values. Sample inside the half-open one-second range.

`fold.compositor.create-effect` accepts `CustomEffect`, `Glow`, `Dissolve`, `CircularWipe`, `FilmLook` and `Grain`. Definitions are ordinary editable graphs. Image-stack definitions expose `source`; transitions expose `outgoing` and `incoming`. Instance `definition` is a document/output reference; `version` must match the interface. `values` map stable control IDs to component arrays. Instance animation uses the host clock. A graph Input receives invocation media; an Image Reference resolves another document. A definition containing Inputs needs an invocation to render; a bare definition is not a self-contained preview.

Use Composition `effects` or Timeline `Effects` operations to attach an ordered stack. Create timeline adjustments with `AddAdjustment` and attach their stack. For Composition, mark a source-less childless layer with `adjustment`; its effects process only lower siblings in its containing group. Adjustment opacity mixes original/processed images. Composition adjustments cannot carry transforms: put spatial processing in the effect graph. Transition intervals must span an adjacent cut and have valid source handles; video transitions do not add audio fades.

Motion `Timing` outputs progress, shaped value, elapsed seconds and duration. It inherits an explicit invocation range, or uses the object/document range when standalone. Connect elapsed/duration to `Timing Segments` for fixed intro/outro seconds with flexible hold; short ranges compress intro/outro proportionally. `Curve` shapes each phase separately. Oscillator retains periodic semantics. Domain-varying Motion fields still execute on CPU; image effects on their rendered output use the GPU.

Motion's canvas uses scene units independently from raster dimensions. Retain the canvas when changing output resolution. Fit/Fill preserve proportions; Responsive preserves logical height and adapts width. `Format` supplies logical size/center/aspect and `pixel_size` (scene units per full-output pixel); `Anchor` provides normalized positioning. Multiply a pixel distance by `pixel_size` when it must remain pixel-fixed. Preview resolution is not a layout input.

For live WGSL, discover `shader_interface` for explicit add/rename/remove migration. Source uses `fn effect(uv: vec2<f32>) -> vec4<f32>` and generated functions named after image/control IDs. Return premultiplied scene-linear RGBA. Current programs are loop-free, with 8 images/32 controls, nearest sampling and conservative full-frame footprints. Native blur operators supply convolution. `fold.compositor.publish-shader` validates a complete candidate Composite on a cancellable revision-guarded worker before saving. Draft graph edits alone do not prove source or backend validity. Invalid shaders fail explicitly on the CPU renderer; never bypass them for a preview or delivery.

## Four-context demo: verified live authoring

[Welcome to Fold](../../../demos/welcome-to-fold.md) was created through live public MCP candidates, rendered on GPU, committed, saved and reopened in the desktop. It exercises Timeline → Composition → Compositing → Motion, a clip Glass stack, a Composition Glitch stack, a graph Glow instance, Dissolve and Circular Wipe transitions. Inspect the saved documents for complete, tool-created shader and interface examples. All fonts are embedded and there are no external assets.

For timeline format, the verified public command is `fold.app.document-settings` with `{document: sequenceId, settings: {format: {width:1920,height:1080,rate:[30,1],frames:540}, timeline:true}}`. Placement does not adopt source format automatically. This command still lacks an advertised argument schema; inspect the resulting sequence's `dimensions` and `rate`.

Build each source Composition with extra duration, then use `place` with explicit `source_start` and `duration`. The demo uses eight-second sources, a half-second source start, six-second clips and one-second transitions centered on adjacent cuts. Transition operations use `{Transition:{transition:{id,outgoing,incoming,start,duration,effect}}}`. Attach clip stacks with `{Effects:{id:clipId,effects:[instance]}}`, and Composition stacks with `{op:"effects",layer:layerId,effects:[instance]}`. Inspect placement-created clip/layer IDs before attaching stacks.

Changing Motion `info` preserves its logical canvas: this demo retained the default 1280×720 canvas while rendering at 1920×1080. Align text before its animated object transform and author positions in logical units. Remove disconnected default compositor Solid/Output nodes after constructing a replacement output path. Send edit objects as JSON objects, not JSON-encoded strings; the MCP wrapper's string-typed descriptions for `edits` and command `arguments` do not match the running public wire contract.

For reopen checks, launch `fold-desktop --agent --project /absolute/project.fold`; a positional filename does not open the project. Rediscover the session and inspect its path/document count before rendering. Render metadata distinguishes full evaluation resolution from MCP's downsampled diagnostic image.

For artist-facing demo clips, make each clip one Composition with direct named Motion object layers and separate compositing layers. A chain of whole-document placements can render correctly while burying text behind Read nodes. Use `fold.app.add-layer-graph` with `kind:"image"` to create Composition-owned image networks, and bind existing Motion objects through `fold.composition.edit` with source metadata `"fold.layer.object": objectId`. The latter synchronizes ownership for selection-to-Network routing. Welcome to Fold was corrected to this structure after user navigation feedback; its original wrapper layout is not the recommended authoring pattern.

Apply image effects to the owning Composition layer when the intended result is a layer modifier. In the live demo correction, `fold.composition.edit` with `{op:"effects",layer:textLayerId,effects:[glowInstance]}` attached the published Glow definition directly to the Motion text layer. Removing the old halo layer and unused graph in the same public batch preserved the text's editable network and produced a verified GPU frame at 14 seconds. Layer selection opens that network while retaining the container Inspector; an explicit node selection changes the Inspector target.
