# Chromatic Motion study

Open [cavalry-chromatic-motion.fold](cavalry-chromatic-motion.fold) in Fold. The project is 720×1280 at 30 fps, ten seconds long, with a five-second cycle at the default drift speed.

Edit **Orbit Dots** in **Chromatic Motion Study**. Its **Chromatic Dots** group publishes 21 controls for dot count/size, layout, timing, five colors, labels, markers, guides, and stipple. Edit **Chromatic Motion — Glow** for the separate blur/gain/Plus treatment.

The [complete public-MCP workflow](../skills/fold/references/procedural-dot-study.md) documents the construction order, layout formulas, keyframe schedule, controls, overlay wiring, glow, edit snippets, and verification. Start with the [Fold skill](../skills/fold/SKILL.md) when authoring through MCP; its [glossary](../skills/fold/references/glossary.md) explains the underlying concepts.

Review the cluster at 0s, stipple at 1s, ring at 2s, wave near 3s, and loop boundary at 5s. Changing Drift Speed requires a new loop check. The project is a procedural interpretation of the [Cavalry reference](https://www.youtube.com/shorts/vCOame09Fns), with overlays authored as renderable content.

The workflow is maintained in the skill so an installed skill carries the instructions without requiring this repository. This page links the demo to that single source of truth.
