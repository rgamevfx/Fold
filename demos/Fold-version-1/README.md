# Fold version 1 — historical artwork

These projects use the retired Motion provider. Preserve them and their evidence;
an unavailable provider must remain opaque through save/reopen. They are not
current-provider tutorials or proof of present runtime limits.

- [Noise reveal project](../Fold-version-1-noise-reveal.fold): stationary text with
  a flickering dot sweep; [preview](noise-reveal.gif) and
  [revision-45 evidence](noise-reveal-evidence.json).
- [Original project](../Fold-version-1.fold): six seconds, 1920×1080 at 30 fps;
  FOLD V1 lettering transitions into a purple wave.
- [Hero](hero.png), [contact sheet](contact-sheet.png) and
  [MCP evidence](evidence.json) retain the original review and numeric-guard findings.

The historical construction used ten Motion nodes, a 60×14 dot grid and a
250×55 text sampling image. Its controls and density limits belong to that
provider/build. Native UI and reopening were not qualified in the original session.
Use the [Fold skill](../../skills/fold/SKILL.md) for current artwork workflows.
