# NOV — Chromatic Pearl Conveyor

Open `cell-type-rust.fold` and view the common Composition **NOV — Chromatic Pearl Conveyor**. The portrait artwork is 500 × 888 at 25 fps. The 12-second document contains two repetitions of a 6-second loop. The GIF is an independently verified 25 fps, 250 × 444 preview of the native six-second cycle. The original agent’s 4 fps preview remains in the trial evidence.

The letters are editable text sampled into circular cells. The embedded DejaVu Sans Bold font survives reopening. Five reusable shaded cell sources supply candy pink, acid mint, electric blue, white and gray. A native dot field surrounds the typography.

Select the Rust asset layer and edit its native group controls:

- **Letters (Unicode characters):** use three characters. Current artwork says `NOV`; Unicode characters are selected independently rather than shaped as a word. Longer text uses its first three characters; fewer characters wrap.
- **Letter size:** 460 px. **Cell spacing:** 24 px. **Letter separation:** 500 px. Keep letter size/separation near these values for the verified wrap clearance; extreme values can expose a seam or clip letters.
- **Candy pink / Acid mint / Electric blue:** change the three colors. White and gray are fixed in the Rust source.
- **Conveyor speed:** connected to the source graph's ordinary Published Control named **Conveyor speed · letters / second**, currently 0.5. Changing it changes the travel speed; the 6-second loop and breathing alignment are verified at 0.5. For another speed, adjust the document duration and breathing keys to match.
- **Cell radius / breathing track:** connected to the ordinary native **Keyframes** node in the source graph. Its Ease keys run 11.5 → 13 → 11.5 px at 0, 1, 3 seconds and repeat every 3 seconds through 12 seconds. Edit those keys, or disconnect the input and set a constant radius.

Use **Edit Rust source** on the asset for structural changes; the paired `cell-type-rust.rs` contains the exact final Rust source. Its embedded-font identity belongs to this project. Source revisions preserve the instance's text, palette, controls and external links.
