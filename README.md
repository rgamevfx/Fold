# Fold

Fold is a video editor, compositor and application for motion graphics and 3D,
built with Rust and Dear ImGui. It is in development; features and file formats
can change.

- **Timeline** arranges media and document outputs in time.
- **Composition and Compositor** combine layers and process images with nodes.
- **Motion** edits 2D shapes, paths, text and images, with Rust scripts for
  procedural artwork.
- **3D** edits spatial objects, materials, lights and cameras.

Artists and agents work on the same project through undoable edits.
The [current-work checklist](docs/current-work.md) distinguishes implemented
features from tested workflows and native artist acceptance.
