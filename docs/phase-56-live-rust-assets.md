## Product and implementation contract

Agents write Rust against a compact creative library: text/shapes, measured alignment, distributions, retained fields/timing, reusable functions, and explicit controls. Compile source on workers inside the running application. Ordinary parameter edits never recompile source. The result is a reusable native asset with typed sockets and artist-facing controls, usable in the common Composition/layer workflow. Compilation/evaluation errors must reach the agent with useful diagnostics.

Two implementations share the asset interface: a Rust program constructs a retained native graph, and custom runtime algorithms use bounded Rust/Wasm nodes inside that graph. Start with native graph generation and reuse the existing Wrangle runtime. Do not introduce a second renderer or attempt to decompile arbitrary Rust into nodes. Saved native constructions evaluate without rerunning author-time source; runtime Wrangles retain their existing compiler/runtime requirements.

Code owns generated internals. Artists own instance values, input connections, parameter animation, placement and surrounding construction. Source updates preserve those through stable parameter IDs. Incompatible/removed ports or manually changed generated internals produce explicit conflicts, never silent deletion. Full arbitrary source/manual-graph reconciliation is a later capability. Reuse native groups, published interfaces, transactions, immutable snapshots, candidate observation and one-entry undo. Keep Motion-specific models in Motion and keep common layer/timing ownership in Composition.

### Follow-up implementation — 2026-10-07

`jobs` accepts `wait_ms` from 0 to 25000. The socket response is deferred while the application continues processing events and worker results; a deadline returns pending without cancelling the job. Waiting replies are bounded and wake on completion or disconnection. The public Python helper now uses this API instead of 50 ms polling; its method-argument collision is also fixed.

Composition now supplies an authoring catalog and typed format/layer/lock/range/keyframe edits. Application coordination synchronizes graph-owned layer state in the same transaction. A regression test exposed Motion rejecting Composition transform channels and ignoring them for referenced objects; validation now accepts common transform channels and evaluation uses the same sampled matrix as Composition, in the object's local clock. The regression checks the animated midpoint after moving the layer range, plus atomic lock rejection and undo/redo.
