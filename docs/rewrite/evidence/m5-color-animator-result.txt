M5 native per-instance Color Animator — 8 October 2026
Uncommitted active rewrite implementation; M3–M5 gates remain pending.

Implemented animator.color_replace through the shared instance sampler. Native
Color Ramp and animated Radial Field supply a straight linear Rec.709 color.
Replacement preserves instance IDs, scale, position and shared prototype data.
Renderer material IDs remain stable as color changes; placement opacity multiplies
alpha and the explicit collection Material supplies lighting properties. Instance
colors override collection base color, including a downstream Material assignment.
RGB uses existing spatial bounds [0,65504]; alpha uses [0,1].

The independent CPU fixture checks all 240 instances at times 2,0,1,2 seconds:
one shared mesh, 240 stable material identities, radial interpolation to HDR RGB
and fractional alpha, scale 0.5, opacity 0.5, retained prototype surface, repeated
color replacement and native-operation context for invalid negative RGB.
Source round trip and public observation of each instance color also pass.
