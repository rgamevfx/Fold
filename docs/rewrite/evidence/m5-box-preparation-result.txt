M5 box prototype preparation — 8 October 2026
Uncommitted active rewrite implementation.

Added fold_render::spatial::primitives::box_mesh, a feature-neutral, fixed-cost
preparation service for the frozen cloner's centered box prototype. Full extents
are explicit caller-unit f32 values in [1e-6, 1e6]. Nonfinite, degenerate and
out-of-range dimensions reject before allocation. The box has 24 vertices,
36 indices, hard outward face normals and independent per-face [0,1] UVs.
Index ranges follow fixed +X/-X/+Y/-Y/+Z/-Z face order. Size edits preserve
face/corner slots and indexed topology. Prepared mesh ownership is Arc-based;
no project model, Bevy state, fallback or new dependency is introduced.

Two CPU tests pass. Independent geometric assertions check welded edge pairing
and opposite directions, outward triangle winding, signed volume against full
extent product and centered bounds for the frozen 0.06 cube, a nonuniform box
and extreme supported aspect ratio. Tests also check face/UV slot correspondence
through size edits and invalid values on every axis. Focused render Clippy passes.
Formatting and package boundary checks pass.

The shared Mesh runtime contract does not yet consume UVs; preparation retains
them explicitly for native geometry provenance. This is not a registered native
Mesh operation, Cloner, rendered box qualification or integrated scene. Native
geometry/evaluator/observation/render conversion wiring remains required. M3–M5
phase gates remain open. No UI was changed by this preparation service.
