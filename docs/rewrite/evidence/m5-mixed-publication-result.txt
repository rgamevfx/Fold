M4/M5 Motion ordered mixed publication — 8 October 2026
Uncommitted active rewrite implementation.

Motion's named Scene video provider now compiles Screen/World outputs from one
native evaluation. Consecutive World entries share depth, camera and lights in one
spatial pass. Screen runs delimit passes and composite in authored paint order;
a subsequent World pass has fresh depth. Shared conversion budget/cancellation and
2048-pass bound prevent unlimited compilation. Screen/spatial public preparation
APIs reuse the same converters. No legacy or CPU spatial fallback was introduced.

Availability: spatial GPU build only for World/mixed frames. Ordinary desktop
feature does not yet enable spatial automatically. Camera Plane and spatial ACES
remain explicitly unavailable. Provider inspection reports build availability.
Screen-only ACES conversion remains supported and passes existing provider tests.
