Uncommitted active rewrite implementation.

Command:
cargo test -p fold-app --features spatial --test motion_spatial native_box_gpu_matches_analytic_slabs_and_retains_shared_prototype_frames -- --ignored --nocapture

Native Motion document snapshots -> rendering::spatial -> shared Vulkan adapter.
The fixture uses two World placements of one unlit box prototype with authored
0.06 m full extents. A new revision grows it to 0.09 m, producing overlapping
coverage; a subsequent revision changes to the rear camera. Frame requests carry
exact 0, 1/24, 2/24 times and revision/camera bindings. Dimensions are 640x220.

An independent f64 slab-intersection oracle uses authored box dimensions and
placement centers, converted to the adapter's explicit f32 representation. It
never reads generated mesh triangles or positions for expected coverage/depth.
Every pixel is checked except silhouette transitions within 1/128 pixel. Interior
pixels must be exactly opaque white, exterior pixels transparent black with zero
reverse-Z depth. Covered axial-depth error must be below 2e-5 m.

Results on llvmpipe Mesa 26.1.6 Vulkan:
- 0.06 m, front camera: 6,715 covered / 133,963 clear / 122 edge exclusions;
  max axial-depth error 6.617765770933204e-7 m.
- 0.09 m, front camera: 15,702 covered / 125,098 clear / zero exclusions;
  max axial-depth error 1.4901161193847656e-8 m.
- 0.09 m, rear camera: 18,113 covered / 122,687 clear / zero exclusions;
  max axial-depth error 1.4901161193847656e-8 m.
- One renderer mesh, two instances. Initial publication and size edit each
  prepare one mesh; changing the camera prepares none and does not respawn
  instances. Held earlier-frame pixels remain unchanged, and mismatched newer
  bindings reject readback.
- Focused spatial application-test Clippy passes, with existing render YUV and
  app source_preparation warnings. Formatting, package boundaries and whitespace
  checks pass.

This is native snapshot/adapter evidence. It does not qualify box lighting,
physical GPU/desktop presentation, normal/narrow artist interaction, public
agent frames, packed cloner performance or the integrated M3–M5 acceptance gate.
