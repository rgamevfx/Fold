M5 native Grid distribution — 8 October 2026
Uncommitted active rewrite implementation.

Registered fold.motion.distribute v1 grid produces native Points, a separate
non-primitive immutable stream for explicit distribution consumers. Defaults are
20 columns, 12 rows, 0.12 m XY spacing and World center [0,0,0]. Position precision
is f64. Coordinates use centered spacing; count changes recenter positions.
Columns/rows are bounded nonnegative integers, total count is at most 100000,
spacing is positive and resulting positions remain within +/-1e6 m. Empty axes
produce no points. Evaluation shares existing work/element/cancellation limits.

Identity is independent of flattened order, dimensions, spacing, center and time:
stream identity uses the operation/asset-instance path and grid slot; cell slots
are the two u32 little-endian column/row coordinates, with stream identity as
upstream. Surviving cells therefore retain IDs on growth/shrinkage. This extends
the M2 UTF-8 slot convention with documented binary grid-cell slots. Source and
schema represent Points explicitly. The graph catalog uses existing controls and
transactions. Observations expose cells, IDs, World/Meters, positions, point
bounds, row-major ordering and grid_cell identity policy with bounded traversal.

- All 15 application observation tests pass. The grid case observes growth and

- Ordinary desktop binaries check, strict Motion UI Clippy and application

No Cloner, random values, Field/Animator or rendered instances are claimed by

M3/M4/M5 gates remain open. Grid cells are not exposed as painted geometry.
