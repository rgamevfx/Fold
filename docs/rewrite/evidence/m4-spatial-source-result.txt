M4 shared spatial image source — 8 October 2026
Uncommitted implementation in the active rewrite worktree.

Shared RenderGraph::Spatial holds an immutable feature-neutral scene and exact
camera/document/revision/time/duration/dimensions binding. Renderer retains one
Bevy adapter on the same Host and consumes its completed RGBA16F image directly.
Multiple source frames retain distinct images. No image readback or CPU image
adapter occurs during graph evaluation. Region rendering preserves the full
camera projection and crops using the source texture's actual precision.
CPU rendering and builds without the spatial GPU feature explicitly reject the
source. ACES graphs reject it until an explicit working-space conversion qualifies.

Vulkan llvmpipe fixture: two spatial sources, ordered premultiplied Over, HDR,
source-only RGBA16F, crop, retained frames, dimension rejection, upstream half-float
saturation propagated through a downstream Over, and recovery all pass.
CPU contract tests cover preserved camera extent, color-space/dimension/camera
rejection, and absence of a CPU rendering fallback. Existing graph/region tests pass.
