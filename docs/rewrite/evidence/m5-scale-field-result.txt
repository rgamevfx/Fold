M5 per-instance scale and radial field — 8 October 2026
Uncommitted active rewrite implementation.

Registered animator.scale_multiply and field.radial using native registry inputs,
shared expression IR and the existing CPU evaluation budget. Radial influence is
clamp(1-length(position-center)/radius,0,1) in World meters. Its registry domain is
Instance with explicit per-element cost. Scale sampling binds incoming instance
identity/index/count/position, isolates sample-local values and child scopes, and
shares budgets/cancellation/identity checks. Text Animator now reuses that same
sampling helper. No alternate expression evaluator or dependency was added.

Native instance records retain positive uniform scale separately from immutable
prototype buffers. Animator multiplies incoming scale and preserves instance IDs,
positions, source-point associations and prototype/distribution Arcs. Rendering
scales prototype geometry and local text glyph offsets before World placement;
CPU observations expose scale and measure the resulting vertices. Graph creation
uses existing controls and inserts an explicit Cloner for Scale Animator. No new
toolbar/panel is introduced.

  tests pass, and all 26 native text/spatial regressions pass.
- Moving radial center (-1,-0.5,0) -> (1,0.5,0) over exact two-second linear Tween,
  radius 1 m, reordered times 2/0/1/0.5/3 seconds, and independent Euclidean-distance
  expectations agree at every one of 240 instances. Scale reaches renderer TRS
  while one prototype mesh remains shared. Positions and IDs remain unchanged.
- The fixture uses explicit shared IR 0.2+0.8*influence to qualify field sampling;
  it does not substitute for the still-required native editable Ramp operation.
- Version-one named-stream random sampling matches the existing frozen function
  per stable instance ID and survives count edits; chained Animators multiply
  scale explicitly. Mid-sampling cancellation and invalid scale context pass.
- All 16 application observation tests pass; the Cloner case checks unit and half
  scale, unchanged prototype vertex count, all instance scale values and bounds.
- Ordinary desktop binary compilation, strict Motion UI Clippy and application
  observation Clippy pass. Existing YUV/source_preparation warnings remain.
- Formatting, package boundaries and whitespace checks pass.

This is native CPU evaluation/conversion and observation evidence. GPU animated
scale, color/rotation Animator modes, native Ramp/Random artist controls, linear
