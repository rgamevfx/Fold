M5 native Linear Field — 8 October 2026
Uncommitted active rewrite; no phase gate is claimed complete.

field.linear exposes Start (m) and End (m), World Vector3 controls, through the
existing registry, inspector and graph transaction path. Defaults are (-0.5,0,0)
and (0.5,0,0). Output is Scalar Field / Instance / World with per-element cost.
Influence is clamp(dot(position-start,end-start)/length_squared(end-start),0,1).
Each endpoint coordinate must be finite and within ±1e6 meters; segment length
must be at least 1e-6 meters. Endpoints accept signals. The shared typed element
expression supplies position; bounded three-component projection executes within
the existing sampler's clock, cache, cancellation and request budget.

Independent CPU fixture: 240 grid instances, Scale Animator via native 0.2 -> 1
Ramp, animated 3D endpoint, reordered samples 2,0,1,2 seconds. Every scale matches
the authored projection formula within 1e-12; both endpoint clamps occur. Source
round trip and instance IDs/positions/source-point correspondence survive. Equal
or near-equal endpoints and an out-of-range endpoint fail with native field context.
