M5 retained logical word groups — 8 October 2026
Uncommitted active rewrite implementation.

The Fold text layout now retains non-whitespace Unicode word-boundary segments
from pinned Parley's existing cluster metadata. Groups are sorted by logical
UTF-8 position, independent of visual/bidi glyph order. Each group retains source
range, cluster indices, glyph indices and an explicit advance-center pivot.
Whitespace is excluded; punctuation follows shaper word segmentation (for example
Hello, can't! becomes Hello / comma / can't / exclamation). This is not an ink-bound
pivot. A word that wraps still has one logical group spanning its positioned glyphs.
No second shaping pass, font substitution or new dependency was introduced.

Native Text retains IDs for word index/range slots, charged to the evaluator's
logical-element budget. Size/wrap edits retain these IDs; arbitrary insertion/edit
correspondence is not inferred. CPU agent observations expose each word's ID, UTF-8
range, member cluster/glyph IDs and pivot with pivot_kind=advance_center. Reporting
walks charge cancellation/budget checks for group and member traversal.
