M5 native word-position Text Animator — 8 October 2026
Uncommitted active rewrite implementation.

Registered fold.motion.text_animator v1 word_position consumes retained Text,
a Screen Canvas Vector2 position signal and a nonnegative exact Duration stagger.
Each logical word samples its position at asset-local time minus index * stagger.
Explicit Scene Time stays global. Local sampling isolates evaluator value/scope
caches, shares the existing budget/cancellation context and retains the original
shaped Layout Arc. Glyph/word correspondence IDs survive animation. Translation
is stored separately from immutable layout data; Outline Text, Screen rendering
and metric extrusion consume the same offsets without reshaping.

CPU observations expose layout_position/layout_pivot separately from evaluated
position/pivot and offset. Moved layout bounds are conservative layout_envelope,
not ink bounds. The graph starter inserts explicit Text and cubic-out Tween
nodes through the existing catalog transaction path. No new dependency or
alternate shaping/rendering engine was introduced.

Verified behavior:
- Frozen 80-to-zero cubic-out entrance, duration 3/5, word delay 7/100,
  reordered positive/negative exact times and stable identities.
- Root offset 1/10 and rate 2 map Scene 3/10 to local 2/5 before word delay;
  explicit Scene Time remains 3/10 for every word regardless of that mapping.
- Branch cache isolation, retained layout sharing, Source round trip, bounded
  evaluation/conversion, cancellation and negative-delay rejection.
- Animated Text and Outline Text produce identical CPU drawing/pixel output.
- O/B/8 extrusion inherits metric translation with unchanged topology IDs.
- Candidate observation reports evaluated offsets/pivots and bounds without
  changing project revision.
- Registered application GPU evaluation at 1/4, 0, 1/2, 3/4, 1/4 uses RGBA16F,
  exact timestamps and retained old frames with no CPU image adapter/readback
  during evaluation. Explicit test readback agrees with CPU to max 0.0002516806
  against tolerance 0.002 on llvmpipe Mesa 26.1.6 Vulkan.

Validation:
- Motion UI library: 45 passed, six existing ignored; reference: 27 passed;
  text/conversion suite: 23 passed before two additional focused cases below.
- Global clock/budget and extrusion tests passed separately after addition.
- Final root-remapping/global-clock focused test passed.
- Application observations: 13 passed. Focused final observation case passed.
- Motion UI check, strict Motion Clippy and application GPU integration-test
  Clippy passed. Existing render YUV and app source_preparation warnings remain.
- Ordinary desktop binaries checked successfully (14.93 seconds).

This qualifies word translation only, not rotation/scale/other text selection
modes, physical normal/narrow artist interaction, complete public frame tooling,
or the integrated cloner scene. M3/M4/M5 gates remain open.
