M5 native Random scalar variation — 8 October 2026
Uncommitted active rewrite; full M3–M5 gates remain pending.

random.uniform is an Artist operation with Minimum, Maximum and Stream controls,
defaulting to 0, 1 and "variation". Output is Scalar Field / Instance / World.
It executes the existing Expr::Random version 1 inside the shared sampler and
maps the sample through minimum + (maximum-minimum)*sample. No second random
implementation or time/index-based seed is introduced. Construction seed, Random
operation UUID, stable instance ID and named stream own the sample identity.
Bounds must be finite, ordered and within ±1e6; equal bounds are permitted. Stream
validation reuses the expression's 1..256-byte policy. Missing instance context
fails rather than supplying an implicit uniform identity.

The native test checks every sampled instance against established random_v1,
reordered times (2,0,1,2), count edits (20,21,20,20 columns), surviving IDs/values,
seed and stream separation, Source round trip, invalid/oversized streams, reversed
or oversized bounds, and native operation context on errors. It uses Scale Animator
to consume scalar variation; this does not qualify rotation application.
