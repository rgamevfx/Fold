The initial fixture failed before GPU rendering because native conversion exhausted
the unchanged one-million-step budget. Shared planar preparation now retains a
bounded LRU of immutable Fill/Stroke partitions keyed by input mesh Arc identity.
It admits at most 64 entries and 16 MiB, conservatively charging all retained input
and result meshes even when another cache also owns them. Meshes remain valid after
cache destruction; cached requests still honor cancellation. This supplements,
rather than replaces, existing geometry/mesh caches; aggregate render memory
qualification remains open.

Additional work reductions:
- Discard clipping fragments that cannot emit a nonzero front-facing f32 triangle.
- Retain fragment bounds rather than recomputing them for each candidate.
- Filter nonintersecting leaf bounds before candidate processing.
- Reject triangle pairs separated by a triangle edge before polygon clipping.
All bounds/half-plane tests are geometric; no raster approximation or depth offset.
Long scalar loops retain bounded cancellation checkpoints. An experiment reducing
BVH leaves from eight triangles to two increased work and was reverted.
