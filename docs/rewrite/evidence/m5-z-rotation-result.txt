M5 native per-instance Z rotation — 8 October 2026
Uncommitted active rewrite; full M3–M5 gates remain pending.

animator.rotation_z_add samples Angle (rad) in the shared incoming instance
context, adds it to local Z rotation and normalizes to [0,2π). Each input angle
must be finite and within ±1e6 radians. Rotation is around the prototype origin;
scale, color, instance/source-point IDs and retained prototypes survive. Native
Random with 0..2π range and stream "rotation" supplies static per-cell variation.
The existing registry controls and graph starter supply native authoring.

Instances expose rotation_z (radians). Instance::point applies local rotation,
uniform scale and instance translation. Observation uses this transform for
vertices/bounds. Spatial conversion rotates prototype/glyph offsets and composes
World quaternion with local Z rotation, retaining one prototype mesh.

Current renderer limitation: its TRS instance representation cannot represent
World nonuniform X/Y scaling after an arbitrary local Z rotation. Conversion
explicitly rejects rotated instances with unequal World X/Y scale, rather than
silently changing transform order. General affine/shear instance composition is
still required for broader rendering support; this record does not close that gap.
