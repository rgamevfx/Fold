Shared planar vector/text mesh preparation — 8 October 2026
M4 preparation; native Camera Plane placement and M3–M5 gates remain open.

Extracted the text mesh cache's indexed-mesh preparation into the feature-neutral
spatial::planar service. It consumes retained vector Drawing paths and produces
separate optional fill/stroke meshes in local coordinates, facing +Z. Explicit
projected scale controls curve subdivision. Paint and placement remain caller
data; callers choose transforms, materials and ordering. Text preparation now
uses this same cache and retains glyph associations and original transforms.
The old private text mesh conversion was removed, not duplicated.

Both parts use the existing GeometryCache/tessellator, preserving even-odd/nonzero
fill rules and stroke geometry. Mesh cache admission remains bounded to 16 MiB
and 256 entries independently of the existing geometry cache. Arc-owned returned
meshes survive cache eviction/destruction. Shared typed errors preserve caller
cancellation/budget stops; no partial Prepared result publishes after a stop.
General drawings validate signed HDR paint without changing geometry.
