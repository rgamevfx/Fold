[0.06,0.06,0.06]. Evaluation consumes the shared box preparation service, retains
24 vertex and 12 triangle IDs plus six authored face regions, and accounts for
logical elements and evaluation steps. Size changes preserve slot identities.
Authored dimensions remain f64; prepared positions/normals/UVs are explicit f32.

Native GeometryData::Mesh distinguishes the box from text extrusion. Material
and World placement accept the mesh without inventing text provenance. Appearance
branches retain the same Arc. Spatial conversion uses a common mesh admission
and instance publication path for boxes and text solids, reusing buffers across
placements, preserving material/transform distinctions and existing limits.
Screen conversion rejects spatial meshes. CPU observations expose topology IDs,
positions, normals, indices, UVs, face regions and measured World bounds, with
precision declared and traversal charged to the existing observation budget.
The graph palette uses the existing registry controls and transaction workflow;
Box needs no dependency starter or new visible panel/toolbar.
