Change:
Deleted the previous per-triangle subtraction/BVH/boundary-union algorithm.
Consistently wound fill/stroke triangle contours feed one NonZero integer overlay
graph; Difference, InverseDifference and Intersect produce paint-region boundary
contours. Shared tessellation converts these to the retained planar meshes.
This avoids internal fragment edges that previously overlapped after subpixel
snapping. Existing partition Arc/LRU ownership and paint compositing are retained.
Source font/layout/path data stays native. No depth displacement or oracle
tolerance changes. Overlay implementation shrinks from 486 to 178 lines.
