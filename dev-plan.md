## Agreed product and execution decisions

Current rules are consolidated in the [product specification](docs/Fold_Application_Product_Architecture.md); implementation details are verified in [architecture.md](docs/architecture.md). These pointers identify the contract to consult before extending each area.

### Reference platform and scope

Linux/GTX 1070 with 8 GB VRAM is the reference configuration, not a broad support claim. One native docked window, multiple panels/viewers, static packages and 2D creative workflows are current scope. Bounded Solver and Rust asset work is shipped; general physics, spatial authoring and runtime plugins remain deferred. See product §§2, 11–13 and 16.

### ACES and OpenColorIO

New projects use ACEScg with pinned OCIO 2.4.2 / ACES 1.3 Studio 2.2.0. Input interpretation, viewer display and delivery transforms remain separate; preserve legacy color interpretation. Core GPU working images currently use RGBA32F, with format-specific resources documented in architecture. See product §7 and Phases 16–18A.

### Viewer cache and resource ownership

Retain the display-image policy in [ADR 0001](docs/adr/0001-viewer-cache.md) with its later BC7 and zoom/region refinements. Immediate RGBA8 and quality-gated BC7 retain display-transformed SDR images, not export sources. The shared Host default is 1 GiB; the presentation-cache limit is 256 MiB. Decoder/driver allocations require separate measurement. See product §§7–8 and Phases 18–19B/28.

### Playback modes and uninterrupted presentation

Viewers have independent Real-time/Every-frame modes and transports. Real-time may skip to preserve timing; Every-frame is consecutive, capped at document fps and muted. One explicit audio monitor does not follow focus. Hold the last valid image through ordinary preparation while rejecting stale publication and preserving correct edit context. See product §§8–9 and Phases 15A/19.

### Project browser and ingest

Project organizes linked assets and documents in bins. Import and placement are distinct actions; a direct drop may combine them in one transaction. Background probing/decoding must not block UI or commit stale targets. Current codec coverage is defined by actual adapters and Phase 55, not the original H.264-only scaffold. See product §§5 and 10, and Phases 12–13/52–55.

### Panel targeting and independent viewers

Editors target documents; viewers choose an editor type within group A–D or an Unlinked output. Inspector selection, viewer binding/time, audio monitoring and delivery selection are independent. Composition owns the shared layer stack and Track/Curve animation; Network opens actual layer graphs. Workspace persistence stays outside authored content. See product §§12–15 and Phases 24/40/51–54.
